# Demo truy vấn Spectral

Tab Spectral nhận một file WAV, tiền xử lý và trích xuất 46 đặc trưng.
Hệ thống chuẩn hóa bằng thông số z-score trong PostgreSQL, sau đó
xếp hạng theo độ đo cosine và trả về 5 file gần nhất.

Khi demo, tải một bản thu iPhone, nghe file truy vấn, kiểm tra bảng
điểm và nghe lại từng kết quả để so sánh với giọng ban đầu.
